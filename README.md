# multi-unit-auction-efficiency

This repository contains code and analysis for researching the efficiency of multi-unit auction mechanisms.

## Project Overview
Multi-unit auctions are widely used in resource allocation (e.g., spectrum, public goods). This project focuses on:
- Simulating different multi-unit auction formats (e.g., uniform-price, discriminatory-price)
- Measuring allocation efficiency under various market conditions
- Comparing theoretical predictions with empirical results

## Requirements
- Python 3.8+
- Dependencies: `numpy>=1.21`, `pandas>=1.3`, `matplotlib>=3.4`
